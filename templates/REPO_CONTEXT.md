## Loading rules

- Read applicable repository guidance, this map, and task-required sources. Preserve native reading requirements and approval rules.
- State: read state and relevant work records; expand to the latest completion only if useful.
- Review: select the unit from native state; read its contract, scope, and evidence; expand to affected architecture, decisions, or code.
- Plan: read state, plans, and work-model rules; add required predecessor closeout and dependencies.
- Architecture: read the relevant section; add supporting code, specifications, or decisions only as needed.
- History: search the decision index or source; read the selected decision and supersession chain.
- Evidence: select the unit and baseline; follow only relevant report/review references.
- Resolve links relative to this map. Explain selectors; a directory or pattern never means read everything.
- Apply declared topic authority to conflicts and report unresolved disagreement. Identify inaccessible references; do not silently replace authoritative information with a summary.
- Stop when sources support the answer or establish a specific gap. Do not recursively load all linked documentation.
- Update this map for changed locations, authority, or reading rules; update routine state in its existing sources.
